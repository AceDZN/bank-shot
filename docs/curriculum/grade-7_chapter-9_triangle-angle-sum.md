## שאלות ותשובות

### מהו הוכחה בקיפול?

הנה דרך פשוטה ויפה לראות למה סכום הזוויות הוא 180^\circ: 1. קחו דף נייר ושרטטו עליו משולש כלשהו. 2. גזרו את המשולש. 3. קפלו את שלוש הפינות (הקודקודים) של המשולש כך שכולן נוגעות בנקודה אחת על אחת הצלעות. 4. שלוש הזוויות המקופלות ייצרו יחד קו ישר - כלומר 180^\circ! שלוש הזוויות של כל משולש, כשמניחים אותן זו ליד זו, יוצרות זווית שטוחה (180^\circ).

### במשולש ABC נתון \angle A = 55^\circ ו-\angle B = 65^\circ. מהו \angle C?

55^\circ + 65^\circ + \angle C = 180^\circ 120^\circ + \angle C = 180^\circ \angle C = 60^\circ

### האם יכול להיות משולש עם שתי זוויות ישרות? הסבירו.

לא. אם שתי זוויות היו ישרות, היינו מקבלים 90^\circ + 90^\circ = 180^\circ, ואז לא היה נשאר מקום לזווית שלישית. היא הייתה צריכה להיות 0^\circ, וזה בלתי אפשרי במשולש.

### הוכיחו שסכום שתי הזוויות החדות במשולש ישר-זווית הוא 90^\circ.

אם \angle A = 90^\circ, אז: 90^\circ + \angle B + \angle C = 180^\circ \angle B + \angle C = 180^\circ - 90^\circ = 90^\circ לכן סכום שתי הזוויות החדות הוא 90^\circ.
